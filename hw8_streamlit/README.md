# IS 445 Homework 8 — UFO Report Patterns

Streamlit app built from the publicly available IS 445 UFO sightings CSV.

Two new visualizations (different from Homework 5): annual sightings by shape with year slider and shape multiselect; percentage duration distribution by shape with independent shape selector.

## Run locally

```bash
pip install -r hw8_streamlit/requirements.txt
streamlit run hw8_streamlit/app.py
```

## Deploy using Streamlit Community Cloud

- Repository: `Namzy100/Namzy100.github.io`
- Branch: `main`
- Main file path: `hw8_streamlit/app.py`

The repo must remain public and the Streamlit app must be deployed publicly. After deployment submit both its live `streamlit.app` URL and the GitHub repository URL.

## Academic integrity

Uses the same source dataset as HW5, but both charts and all write-up paragraphs are original to HW8; includes a disclosure in the app of the dataset overlap and chart differences.
